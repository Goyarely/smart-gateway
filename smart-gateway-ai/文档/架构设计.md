## 一、项目定位

多模态边缘智能网关。原为**纯 C、无 UI** 的 epoll 高并发网关：

- 设备接入（注册 / 心跳 / 上报 / 超时踢出）
- 命令路由（SET_LIGHT / SET_FAN / SET_SCENE）
- 本地规则引擎（高温开风扇 / 光照不足开灯）
- 自研轻量 MQTT 3.1.1 客户端（云接入）

**本次目标**：为其接入一块 **LVGL 触摸屏控制面板**（1024×600），用于可视化管理设备、下发控制指令。

## 二、整体架构

```
┌───────────────────────────────┐         TCP:8888        ┌───────────────────────────────┐
│  进程 A：./server  (网关)       │  自定义二进制帧(协议)     │  进程 B：./lvglsim (控制面板)    │
│                               │ ◄────────────────────► │                               │
│ · epoll 阻塞主循环             │                         │ · LVGL 主循环                  │
│ · 设备注册/心跳/上报            │                         │ · SquareLine 导出的 UI          │
│ · 规则引擎 / MQTT 云接入        │                         │ · 收发网关协议帧                │
│ · 面板也作为一台"设备"接入       │                         │ · 展示/控制 灯光、风扇、窗帘等    │
└───────────────────────────────┘                         └───────────────────────────────┘
```

**核心原则**：

1. **进程分离**：网关与 UI 是**两个独立进程**，通过 TCP:8888 通信。网关崩溃不影响面板，反之亦然。
2. **server 零改动**：UI 面板复用现有二进制协议，作为网关的一台"面板设备"接入，无需修改 server 源码。
3. **到时直接拷贝**：LVGL 核心、驱动后端、SquareLine 导出代码，届时**整体拷贝**进本项目，不采用软链接/子模块方式。

## 三、进程模型

| 维度 | ./server（网关） | ./lvglsim（面板） |
|------|------------------|-------------------|
| 主循环 | `epoll_wait` 阻塞循环 | `driver_backends_run_loop()` → `while(1){ lv_timer_handler(); }` |
| 线程 | 单线程 | 单线程（LVGL 主循环） |
| 通信 | accept 所有设备连接 | 主动 connect server:8888 |
| 角色 | 服务端 | 客户端 + 一台"面板设备" |
| 保活 | 5s 扫描，3 次无心跳踢出 | 周期性发 `HEARTBEAT` |

**LVGL 主循环内做网络收发**：用 `lv_timer_create(cb, period, NULL)` 周期回调完成——
- 收帧：读取 socket → 环形缓冲 → 拆帧 → 更新 UI 控件
- 发命令：控件事件回调里直接 `send` 控制帧

由于收发都在 LVGL 主循环（单线程），**天然线程安全，无需互斥锁**，也无需 pthread 同步。

## 五、模块职责

### 1. 网关侧（现有，不变）

| 模块 | 职责 |
|------|------|
| `net_server.c` | epoll 事件驱动服务器 + 命令路由 + 超时踢出 |
| `protocol.c` | 帧编码/解析 + CRC16 查表 |
| `ringbuf.c` | 环形缓冲 + 拆帧 |
| `device.c` | 设备哈希表 + 心跳 + 超时扫描 |
| `rule_engine.c` | 本地规则引擎 |
| `mqtt_client.c` | 自研 MQTT 3.1.1 客户端 |

### 2. 面板侧（lvglsim 进程，已实现）

| 模块 | 职责 | 来源 |
|------|------|------|
| `src/main.c` | LVGL 入口：初始化 → 驱动后端 → `ui_init()` → 控件命令绑定 → run_loop | 自写 |
| `src/ui_bridge.c/h` | 面板<->网关协议客户端：连接/注册/心跳/收帧/发命令，与 UI 解耦 | 自写 |
| `src/protocol.c/h` | 帧编解码 + CRC16（面板侧也用它发包/拆包） | 自写 |
| `src/json_util.c/h` | 自研轻量 JSON（MQTT 上报/天气等用） | 自写 |
| `ui/`（SquareLine） | 界面绘制、控件事件回调 | SquareLine Studio 导出 |
| `third_party/lv_drivers` | SDL(FBDEV) 显示 + EVDEV 触摸输入 | 从 lv_port_linux 拷贝 |
| `third_party/lvgl` | LVGL 核心库 | 从 lv_port_linux 拷贝（9.x，Kconfig 构建） |

**面板收发逻辑（ui_bridge.c）**：
- 连接网关(server:8888) → 发 `REGISTER` → 收到 `REGISTER_ACK` 后每 2s 发 `HEARTBEAT`
- `lv_timer` 周期调 `ui_bridge_poll()`：`recv` → 粘包拆帧 → 处理 `DATA_REPORT`/`SET_ACK`
- 通过 `ui_bridge_status_cb` 回调通知 UI 更新状态 Label

**控件命令下发（src/main.c）**：
- 给 SquareLine 导出的 Slider/Switch 额外挂事件回调（不改导出文件）
- 灯光→`SET_LIGHT`(0-100)、风扇→`SET_FAN`(%映射0-2400)、窗帘/空调→`SET_SCENE`
- 控件回调调 `ui_bridge_send()` 下发控制帧

**线程模型**：单线程（LVGL 主循环），网络收发在 `lv_timer` 回调内完成，天然线程安全，无需互斥锁。

## 七、通信协议

面板作为普通设备接入，帧格式与现有协议完全一致：

```
magic(2) | ver(1) | len(2) | type(1) | dev_id(4) | seq(2) | crc(2) | payload
 0xAA55                                                                   CRC16 覆盖整帧
```

**命令类型**：

| 值 | 命令 | 方向 | payload |
|:--:|------|------|---------|
| 0x01 | REGISTER | 面板→网关 | 无 |
| 0x02 | REGISTER_ACK | 网关→面板 | result |
| 0x03 | HEARTBEAT | 面板→网关 | 无 |
| 0x04 | SET_LIGHT | 面板→网关(转发设备) | 亮度 0-100 |
| 0x05 | SET_FAN | 面板→网关(转发设备) | 转速 0-2400 |
| 0x06 | SET_SCENE | 面板→网关(转发设备) | 场景组合 |
| 0x07 | DATA_REPORT | 设备→网关→面板 | sensor + value |
| 0x08 | SET_ACK | 设备→面板 | result |

**面板 dev_id 建议**：`0x00F10001`（独立于真实传感器设备，避免冲突）。
**保活**：面板必须周期发 `HEARTBEAT`（server 每 5s 扫描，3 次无心跳踢出），建议 2s 一次。

- **心跳保活**：面板必须周期发 HEARTBEAT（2s），否则 server 5s 超时踢出
- **图片缓存**：`.config` 的 `CONFIG_LV_CACHE_DEF_SIZE` 必须 ≥8MB，否则 400×400 图解码报错
- **CMake GLOB**：SquareLine 导出会生成 `ui/images/`，GLOB 必须包含 `ui/images/*.c`，否则链接报 `undefined reference to ui_img_*`
- **风扇值 bug**：`net_server.c` 的 `on_rule_action` 用 `payload[0] = value & 0xFF`，风扇转速 1800/2400 超出单字节被截断。面板已按双字节发送 SET_FAN，网关侧需改双字节接收
- **驱动后端 API 兼容性**：sdl.c 等用通用 9.x API，与 9.6 兼容
- **SquareLine 导出路径**：`.slp` 目前 `uiExportFolderPath` 为空，需在 Studio 里手动设置
